# 🎵 بوت ديسكورد للموسيقى والردود التلقائية

بوت ديسكورد متكامل لتشغيل الأغاني من يوتيوب والرد التلقائي على الرسائل.

## ✨ المميزات

### 🎶 ميزات الموسيقى
- تشغيل الأغاني من روابط يوتيوب مباشرة
- قائمة انتظار للأغاني
- إيقاف مؤقت واستئناف
- تخطي الأغاني
- عرض قائمة الأغاني

### 💬 الردود التلقائية
البوت يرد تلقائياً على الكلمات التالية:
- **مرحبا** → ترحيب باسم الشخص الذي كتب الرسالة
- **السلام عليكم** → "وعليكم السلام ورحمة الله وبركاته 🙏"
- **صباح الخير** → "صباح النور والسرور! ☀️"
- **شكرا** → "العفو! في خدمتك دائماً 🙌"
- وغيرها الكثير...

### 👋 الترحيب الاحترافي
- رسالة ترحيب تلقائية عند دخول عضو جديد للسيرفر
- تصميم Welcome Card بصورة PNG يبرز اسم العضو وصورته وترتيبه في السيرفر
- رسالة لطيفة عند دخول عضو للروم الصوتي
- اختيار قناة الترحيب تلقائياً أو تحديدها من ملف `.env`
- رتبة تلقائية اختيارية للأعضاء الجدد

## 🚀 التثبيت

### 1. المتطلبات
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أعلى)
- [FFmpeg](https://ffmpeg.org/) (مطلوب لتشغيل الصوت)

### 2. إنشاء بوت ديسكورد
1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. اضغط على "New Application"
3. اكتب اسم البوت واضغط "Create"
4. اذهب إلى قسم "Bot" من القائمة الجانبية
5. اضغط "Add Bot"
6. اضغط "Reset Token" ثم انسخ الـ Token
7. **مهم:** فعّل الخيارات التالية تحت "Privileged Gateway Intents":
   - PRESENCE INTENT
   - SERVER MEMBERS INTENT
   - MESSAGE CONTENT INTENT

### 3. دعوة البوت للسيرفر
1. اذهب إلى قسم "OAuth2" > "URL Generator"
2. اختر الصلاحيات التالية من "SCOPES":
   - `bot`
   - `applications.commands`
3. اختر الصلاحيات التالية من "BOT PERMISSIONS":
   - Send Messages
   - Embed Links
   - View Channels
   - Connect
   - Speak
   - Use Voice Activity
   - Manage Roles (اختياري إذا تريد رتبة تلقائية)
4. انسخ الرابط وافتحه في المتصفح لدعوة البوت

### 4. إعداد المشروع

```bash
# تثبيت المكتبات
npm install

# تحميل محرك yt-dlp لتشغيل أغاني يوتيوب
npm run setup

# نسخ ملف الإعدادات
copy .env.example .env

# افتح ملف .env وضع الـ Token
# DISCORD_TOKEN=your_bot_token_here

# تشغيل البوت
npm start
```

### 5. إعداد الترحيب

افتح ملف `.env` وعدّل القيم حسب سيرفرك:

```env
YTDLP_COOKIES_FROM_BROWSER=
YTDLP_COOKIES_FILE=
YTDLP_JS_RUNTIME=node
YTDLP_EXTRACTOR_ARGS=youtube:player_client=android
WELCOME_CHANNEL_ID=
WELCOME_COLOR=#5865F2
WELCOME_BANNER_URL=
AUTO_ROLE_ID=
```

- `YTDLP_COOKIES_FROM_BROWSER`: اتركه فارغاً. إذا طلب YouTube تحقق "not a bot"، يمكن وضع `chrome` أو `edge` بعد موافقتك على استخدام جلسة المتصفح.
- `YTDLP_COOKIES_FILE`: بديل اختياري إذا لديك ملف cookies مخصص.
- `YTDLP_JS_RUNTIME`: اتركه `node` حتى يساعد yt-dlp في استخراج روابط YouTube الحديثة.
- `YTDLP_EXTRACTOR_ARGS`: اتركه `youtube:player_client=android` لتقليل أخطاء YouTube 429 بدون cookies.
- `WELCOME_CHANNEL_ID`: ضع ID قناة الترحيب، أو اتركه فارغاً ليختار البوت قناة مناسبة.
- `WELCOME_COLOR`: لون إطار رسالة الترحيب.
- `WELCOME_BANNER_URL`: رابط صورة تظهر داخل رسالة الترحيب.
- `AUTO_ROLE_ID`: رتبة تلقائية اختيارية للأعضاء الجدد.

## 📋 الأوامر

### أوامر الموسيقى
| الأمر | البديل العربي | الوصف |
|-------|---------------|-------|
| `!play [رابط يوتيوب]` | `!شغل` | تشغيل أغنية من رابط |
| `!skip` | `!تخطي` | تخطي الأغنية الحالية |
| `!stop` | `!ايقاف` | إيقاف الموسيقى والمغادرة |
| `!pause` | `!توقف` | إيقاف مؤقت |
| `!resume` | `!استمر` | استئناف التشغيل |
| `!queue` | `!قائمة` | عرض قائمة الأغاني |
| `!join` | `!تعال` | الانضمام للقناة الصوتية |
| `!leave` | `!اخرج` | مغادرة القناة الصوتية |

### أوامر عامة
| الأمر | الوصف |
|-------|-------|
| `!help` | عرض قائمة الأوامر |
| `!ping` | فحص سرعة البوت |
| `!info` | معلومات عن البوت |

```javascript
const autoResponses = {
    'كلمتك': 'الرد الذي تريده',
    // أضف المزيد هنا...
};
```

## 🔧 تثبيت FFmpeg على Windows

1. حمّل FFmpeg من [هنا](https://www.gyan.dev/ffmpeg/builds/)
2. اختر "ffmpeg-release-essentials.zip"
3. فك الضغط في مجلد مثل `C:\ffmpeg`
4. أضف `C:\ffmpeg\bin` لمتغيرات البيئة PATH
